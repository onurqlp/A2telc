# AYDA telc Deutsch A2 Bilgilendirme Sitesi

GitHub Pages üzerinde doğrudan çalışan, bağımlılıksız statik web sitesi.

## Yayınlama

1. `index.html`, `style.css` ve `script.js` dosyalarını repository ana dizinine yükleyin.
2. GitHub'da **Settings → Pages** bölümünü açın.
3. **Deploy from a branch** seçeneğini ve ardından `main` / `(root)` ayarını seçip kaydedin.

Site herhangi bir kurulum, npm paketi veya derleme adımı gerektirmez.

## Adres ayarı

Yayın adresiniz belli olduğunda `index.html` içindeki `canonical` ve `og:url` değerlerini kendi GitHub Pages adresinizle değiştirin.

## Dosyalar

- `index.html` — tüm içerik ve sayfa yapısı
- `style.css` — responsive tasarım
- `script.js` — menü, accordion, video modal ve gezinme davranışları
